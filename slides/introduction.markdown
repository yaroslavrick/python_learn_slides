## A short history

- 1991 — Python 1.0, designed by Guido van Rossum
- 2000 — Python 2.0
- 2008 — Python 3.0 (intentionally backwards-incompatible)
- 2020 — Python 2 EOL
- Steady annual cadence since 3.9: roughly one minor release per year

Note: Python 2 is dead. Don't write new code for it.

## Implementations

| Implementation | Description |
| --- | --- |
| **CPython** | Reference implementation. What you almost always use. |
| PyPy | JIT-compiled, faster for long-running code. |
| MicroPython | Trimmed runtime for microcontrollers. |
| Pyodide | CPython compiled to WebAssembly. |

Note: When people say "Python", they usually mean CPython.
